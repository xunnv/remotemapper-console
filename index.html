RemoteMapper 控制台

插好 USB 线，点下面按钮即可。不需要装任何软件。
未连接
点「连接设备」，在弹出的窗口里选 RemoteMapper，然后点「连接」。
蓝牙
WiFi 无线电
管的是整块 WiFi 无线电（连路由器和开热点共用同一个射频）。关掉之后网页打不开，只能用这个串口页面再打开。
设备
相当于拔插一次 USB。重启约 10 秒，之后点「连接设备」重新连上即可。
手动发命令（高级）
可用命令：status / reconnect / reset_keys / wifi scan / wifi set / wifi policy / wifi status / log on / log off / log status / help
